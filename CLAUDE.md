# CLAUDE.md

This file provides guidance to Claude Code when working in this repository. The shared instructions for every AI assistant live in [AGENTS.md](AGENTS.md) and are imported below, so Claude Code loads them at the start of every session.

The design is being tried out in a companion Unreal Engine 5.8 prototype project, `MmoSurvivalGame`, kept outside this repository. It reads this document as canon and does not change it on its own. When the user brings a finding back from it, fold the finding into the design document and its `(Technical)` companion as usual. On a machine where the prototype is checked out, its local path is recorded in the untracked `CLAUDE.local.md` imported below.
